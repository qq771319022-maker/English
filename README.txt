DC Engineer English V6

本版本基于 V5，保留原有 3538 条词库、在线语音、系统语音回退、SRS 学习记录和收藏功能。

V6 修复：
1. 修复“开始今日学习”点击无反应、一直显示“正在计算今日任务”的问题。
2. 修复 JavaScript 缺少 $() 元素选择器导致的运行错误。
3. “添加到手机桌面”按钮固定显示，不再依赖浏览器是否触发安装提示。
4. 支持浏览器原生安装提示；不支持时给出 Android Chrome 的添加到主屏幕路径。
5. 增加 Service Worker 更新检查。
6. 每日学习日期改为手机本地日期，避免 UTC 跨日造成统计偏差。
7. 不改变原有 localStorage 学习进度键，升级后学习记录继续保留。

DC Engineer English PWA V8

本版重点：
1. 每日学习任务固定化：每天生成一次任务计划，不会因为刷新页面而随机换词。
2. 每日任务 = 日常新词 + 专业新词 + 到期复习。
3. 默认：20个日常新词 + 10个专业新词 + 最多20个复习。
4. “当日已完成”的定义：必须在词卡详情页点击一次“忘记/困难/记得/简单”。仅浏览、打开详情或播放发音不算完成。
5. 专业英语会进入每日学习任务，但专业词库仍可在“专业”页面单独浏览。
6. 修改每日数量后会重新生成当天未完成的任务计划。
7. 保留在线语音（StreamElements）+ Android系统语音回退。
8. GitHub Pages根目录部署，文件全部放在仓库根目录。

安装：
Android Chrome打开Pages网址 -> 我的 -> 安装到手机桌面。
如果按钮没有弹窗，使用Chrome右上角菜单 -> 安装应用 / 添加到主屏幕。

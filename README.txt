DC Engineer English PWA V19

本版本继续沿用 V18 的 UI、学习完成逻辑、固定浅色主题和底部五栏导航，并正式完成词库扩充方案。

词库数量
- 3600 个唯一英文词条，全部按“唯一单词”统计，不再用重复学习记录凑数量。
- 日常/工作词汇：来自本地英文高频词表筛选，去除明显人名等噪声后加入。
- 专业词汇：增加数据中心、电气、柴油发电机、UPS、MV/LV、继保、测试、PPM、MOP/SOP/PTW、消防及BMS/SCADA等真实工程术语。

词义、例句、读音
- 原 V18 已审核词条继续保留本地内容。
- 本次新增词条不使用虚构的“占位释义/占位例句/伪音标”。
- 新词打开词卡时，优先调用 UAPI 英文词典接口，读取中文释义、英美音标、词性、双语例句、常见短语等，并缓存到手机本地。
- UAPI 不可用时，回退到 Free Dictionary API 获取英文释义、音标和例句；不会把机器猜测的中文释义冒充为正确释义。
- 单词播放优先使用在线词典的英式/美式发音音频，失败后再回退到现有在线 TTS / 系统语音。

注意
- V19 的“3600唯一词条”是真实单词数量；但为了保证新增词条的释义、例句和音标不被我硬编，新增词条采用“在线词典验证 + 本地缓存”的方式。
- 因此首次打开某个新增词条时需要网络。成功加载一次后，该词条资料会缓存到浏览器本地。
